기획 도구 모음 — 디자인 시안

동일한 포탈 콘텐츠를 4가지 디자인 스타일로 재해석한 시안입니다. 카드를 눌러 각 시안을 미리 보세요.

[ + ] OpenCode · 터미널/모노스페이스
시안 A

OpenCode — 터미널 모노스페이스

크림 캔버스 + 100% 모노스페이스 + ASCII 브래킷 마커. 맨페이지처럼 단정하고 텍스트 중심.
Shopifi · 시네마틱 블랙 + 민트
시안 B

Shopifi — 시네마틱 + 트랜잭션

블랙 시네마틱 히어로 + 크림/민트 카드. 얇은 디스플레이 타입과 알약 버튼.
Spotifi · 다크 + 그린 액센트
시안 C

Spotifi — 다크 플레이어 UI

니어블랙 사이드바 레이아웃 + 그린 액센트 + 원형/알약 컨트롤. 앱 같은 밀도.
Runwai · 에디토리얼 모노크롬
시안 D

Runwai — 에디토리얼 모노크롬

흑백 + 시네마틱 다크 히어로 + 헤어라인 구분선. 검정 알약 CTA의 절제된 갤러리 톤.
현재 운영 중인 포탈(public/index.html)은 그대로 두고, 시안은 /mockups/ 아래 별도 파일로 추가했습니다.
